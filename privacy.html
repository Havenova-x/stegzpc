Privacy Policy

Effective 23 October 2026. Applies to StegZ for Windows, StegZ for Android and this website.

In short

  • No accounts, no ads, no analytics, no tracking in the apps.
  • Your files, file names and passwords never leave your phone or PC.
  • Passwords are never stored. If you forget one, the content can't be recovered.
  • The apps only fetch small public files from our website and GitHub to check for updates and news.

What StegZ collects

Nothing. StegZ doesn't collect, keep or share personal information. We have no user accounts and no database of users.

Your files and passwords

Everything you hide, lock or compress is processed on your device. Passwords are never saved. If you forget one, nobody, including us, can recover the protected content.

On Android, files you create or open are kept in the app's private library on your phone until you delete them. To remove them, use Settings > Delete all StegZ data, or uninstall the app.

What the apps use the internet for

  • Downloading a small public announcement file (announcement.json) from the StegZ website or GitHub.
  • On Windows, checking for a new version and, if you accept, downloading the installer from GitHub Releases.

Nothing about you or your files is sent. Like any web server, the host may see your IP address in its normal logs.

Android permissions

StegZ for Android uses Android's own file picker and folder picker, so it needs no storage permission. It uses network access only for the update and announcement checks described above.

This website

  • No ads, no analytics and no tracking cookies.
  • Your light or dark mode choice is saved in your browser's local storage. It never leaves your device.
  • The download page shows how many times StegZ has been downloaded. To do this, your browser asks GitHub's public service for the total, so GitHub can see your IP address.
  • Downloads are served by GitHub Releases. GitHub's own privacy statement applies to that connection.
  • The website is hosted by a third-party static host, which may keep standard server logs.

Children

StegZ collects no personal data from anyone, including children.

Changes to this policy

If this policy changes, the new version will be posted on this page with a new effective date.

Contact

Questions about privacy? Open an issue on our GitHub support page.
