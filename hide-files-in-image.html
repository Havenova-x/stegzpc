    How to hide files inside an image

    Open the Hide tab, drop a carrier image, add the files you want to tuck inside, optionally set a password, then press Create. Your original image is never overwritten.

    Supports JPG, PNG and BMP carriers

    Folders can be hidden too

    A new image is saved alongside the original

    Download StegZ - freeSee features

    Will social media keep the hidden data?

    Usually not - most platforms re-compress uploads, which removes it. Share the file directly (cloud drive, email attachment) instead.
