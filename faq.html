    Frequently asked questions

    Answers about StegZ, steg, .stegz files, passwords, self-destruct and updates.

    What is StegZ?

    A free Windows utility for privacy and organisation: hide files in images, create .stegz archives, password-protect and optionally self-destruct them.

    Is steg the same as encryption?

    No. Steg conceals that something is there; encryption scrambles it. StegZ lets you combine both with an optional AES-256 password.

    Can StegZ open stegs made on another PC?

    Yes - any StegZ build can open files made by another StegZ, as long as you have the password if one was set.

    How is StegZ spelled?

    S-t-e-g-Z. People also type stegsz, stes or steg z - they all lead here.

    Does it replace my zip tool?

    It covers everyday zipping and unzipping, plus extras zip tools do not have.

    Which compress format should I choose?

    Use .zip to share with anyone. Use .stegz when you want a checksum, a password or self-destruct.

    Does compression lose quality?

    No. The compression is lossless - what you extract is identical to what you packed.

    Can StegZ unzip password zips?

    StegZ's unzip is for normal zips. Password protection is available when you create .stegz archives or hide files in images.

    Is .stegz secure?

    The format lock stops casual tools. For real confidentiality, set the AES-256 password.

    It says wrong password or damaged - why?

    StegZ cannot tell those apart safely. Re-check the password; if it is right, the file was probably altered or cut off in transit.

    Will social media keep the hidden data?

    Usually not - most platforms re-compress uploads, which removes it. Share the file directly (cloud drive, email attachment) instead.

    Is this military-grade steganography?

    No marketing claims here. StegZ is for privacy and tidiness, and pairs steganography with real AES-256 passwords when you need protection.

    Can 7-Zip open it?

    StegZ adds a format lock, so generic archive tools will not read the payload. Use StegZ.

    How do I know an image has hidden data?

    Run it through the Scan tab. It reports whether StegZ data is present and its size.

    Does scanning use up a burn-after-reading limit?

    No. Only a successful extraction counts.

    I forgot the password. Can you recover it?

    No. There is no backdoor by design.

    Is AES-256 unbreakable?

    It is considered very strong; the weak point is usually the password, so use a long one.

    Can it delete other files on my PC?

    Never. It only wipes the payload inside the exact file you made.

    What if I open it by mistake?

    That counts. Confirm carefully when creating one.

    Is this for hiding illegal content?

    No - you are responsible for what you store. See the Terms page.

    Where is the checksum stored?

    In the archive header, and verified before any file is written out.

    Does it need admin rights?

    The installer asks once for permission to install in Program Files. The app itself runs normally.

    What does StegZ send over the internet?

    Only update checks: two small public JSON files, then the installer if one is available. Nothing about you or your files.

    Will rename overwrite a file with the same name?

    No, it stops and tells you.

    Is StegZ really free?

    Yes. No ads, no accounts.

    Does the picture change?

    The visible picture is identical. The file is just larger.
