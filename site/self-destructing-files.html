    Self-destructing files that really wipe

    Opt in per archive and combine rules: a date, a limit on opens (viewing can count too), or a timer that starts when someone first opens it. When a rule is met StegZ overwrites the hidden payload with zeros.

    Date, open limit and timer after first open

    You must confirm at creation - it is irreversible

    Only the archive you created is affected; copying it first keeps an untouched copy

    Can it delete other files on my PC?

    Never. It only wipes the payload inside the exact file you made.
