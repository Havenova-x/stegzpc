# StegZ Privacy Policy

Effective 23 October 2026. Applies to StegZ for Windows, StegZ for Android and the StegZ website.
Full version: https://stegz.vercel.app/privacy.html

## In short
- No accounts, no ads, no analytics, no tracking in the apps.
- Your files, file names and passwords never leave your phone or PC.
- Passwords are never stored. If you forget one, the content can't be recovered.
- The apps only fetch small public files from the StegZ website and GitHub to check for updates and news.

## What StegZ collects
Nothing. StegZ doesn't collect, keep or share personal information.

## Your files and passwords
Everything you hide, lock or compress is processed on your device. On Android, files you create or open are kept in the app's private library until you delete them (Settings > Delete all StegZ data, or uninstall the app).

## Internet use by the apps
- Downloading a small public announcement file (announcement.json) from the StegZ website or GitHub.
- On Windows, checking for a new version and, if you accept, downloading the installer from GitHub Releases.

Nothing about you or your files is sent. Like any web server, the host may see your IP address in its normal logs.

## Android permissions
StegZ for Android uses Android's file picker and folder picker, so it needs no storage permission. Network access is used only for the update and announcement checks above.

## This website
No ads, analytics or tracking cookies. Your light/dark choice is saved in your browser's local storage. The download page asks GitHub's public service for the download total, so GitHub can see your IP address. Downloads are served by GitHub Releases.

## Children
StegZ collects no personal data from anyone, including children.

## Changes
Updates will be posted at the link above with a new effective date.
