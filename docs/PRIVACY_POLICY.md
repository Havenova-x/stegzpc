# StegZ Privacy Policy (Android and Windows)
StegZ runs on your device. No accounts, no analytics, no ads, no tracking. Your files, file names and passwords never leave your phone or PC.
The only network use is downloading small public announcement files (announcement.json) from the StegZ website (stegz.vercel.app / GitHub). Nothing about you or your files is sent; the web host may see your IP address in normal server logs. The Windows app can also download its own updates from GitHub.
StegZ for Android uses Android's file picker and folder picker, so it needs no storage permission. Files you create or open are kept in the app's private library on your phone until you delete them (Settings > Delete all StegZ data, or uninstall the app).
Passwords are never stored. If you forget one, the protected content cannot be recovered. Contact: via the website stegz.vercel.app.
